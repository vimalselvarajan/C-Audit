# Reproducible evidence bundles

`strategic-sequence.tar` is the first bundle produced by `caudit bundle`. It
contains 97 public artifacts from the five-repetition CASTLE analyzer-control
pilot and the durable CVE-pair run, plus an internal manifest and regenerated
tables. The adjacent `.sha256` is the external release checksum.

Regenerate it with the command in
[the attribution and bundle guide](../../my_docs/guides/attribution-and-bundles.md).
Identical inputs produce byte-identical tar bytes.
